下界 (LB) 與上界 (UB) 收斂過程
藍線=下界估計，綠虛線=當前最優上界。當兩線接近時，演算法收斂，剪枝效果最佳。
演算法流程
① 初始化
UB = ∞
→
② 選擇節點
最小下界優先
→
③ 計算下界
LB = max(LB₁,LB₂)
→
④ 剪枝判斷
LB ≥ UB → 回溯!
→
⑤ 更新最優
UB = 新 Makespan
核心回溯機制：當某個排程分支的下界估計 LB ≥ 當前最優上界 UB 時，系統立即剪枝（回溯），放棄該分支的所有子節點，大幅縮小搜索空間。
下界計算公式
LB₁ = maxm(機器 m 的當前佔用時間 + 剩餘工作的最小加工時間)
LB₂ = maxj(工作 j 的最早可能完工時間)
LB = max(LB₁, LB₂, 當前已排程最晚結束時間)
